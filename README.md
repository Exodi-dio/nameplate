# Nameplate

A straightforward Geometry Dash mod that draws your own username in a pickable bundled
font, with customisable gradient colours for the text fill and the outline.

## Features

- 8 fonts bundled with the mod — no TTF hunting required
- Two-colour gradient for the text fill (top + bottom)
- Two-colour gradient for the outline (top + bottom)
- Live preview of your actual username
- Saves your font and colours automatically
- Only ever shows your own account name

## Install

Download the latest `.geode` from the [releases page](https://github.com/Exodi-dio/nameplate/releases)
and open it with Geode Mod Loader.

## Building

Requires the Geode SDK. See `.github/workflows/build.yml`.
